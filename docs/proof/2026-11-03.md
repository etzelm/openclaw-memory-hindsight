The four NOT RUN rows need an owner direct-chat turn. The host only mints an owner-private
audience for a session whose root has `chatType: "direct"` and an owner sender, which
`chat.send` creates. `openclaw gateway call chat.send` from an agent's exec is refused by
design ("Subagent session messages must use the task completion path ... Do not retry through
another CLI route"), and the proof did not work around that guard. `scripts/live-proof.sh` runs
these turns from an operator terminal (one command, below).

## P1-3 (audience currency at agent_end), from host source

`attempt-finalize.ts` calls `runAgentEndSideEffectsAsync`, which awaits the completed-turn
snapshot and then starts `runAgentHarnessAgentEndHook` with `void` (not awaited). That helper
awaits the message loader before `hookRunner.runAgentEnd`. Meanwhile `run-attempt-dispatch.ts`
releases the run's memory audience in the attempt's `finally`. A handler that calls
`assertMemoryAudienceCurrent()` at `agent_end` therefore races the release. The plugin no longer
calls it there (unit test "retains after the run released its audience"). The live harness
confirms the outcome: an `openclaw:<session>:run:<runId>` document in the bank after turn 1.

## Remaining proof: one command for an operator terminal

On the Studio, from any checkout of this repo (`--ref develop` builds a fresh clone of `develop`;
without `--ref` the script builds the current checkout):

```sh
HINDSIGHT_URL=http://<hindsight-host>:8888 scripts/live-proof.sh --ref develop --token-file ~/path/to/hindsight-api-token
```

It builds and packs, installs the tarball into a throwaway Gateway (port 18900, loopback, Bonjour
off), runs four turns on a fresh owner direct session through `chat.send` (fact, a longer turn
that crosses `forceFlushTranscriptBytes: "2kb"`, a recall question, `/learn`), lists the bank's
documents (`openclaw:` = auto-retain, `openclaw-flush:` = flush), runs `memory.search`, greps the
Gateway log, and deletes the bank and the state. With the local model one turn can take 15
minutes; set `MODEL_BASE_URL` / `MODEL_ID` for a faster OpenAI-compatible endpoint.
`--setup-only` was run from agent exec on 2026-11-03 (install, doctor, `memory.status` ready,
cleanup) to check the script itself.
